NumPy (short for Numerical Python) is the base library for numeric computing in Python.
Its main object is the ndarray (N-dimensional array) — a fixed-type block of memory, like a Java primitive array, not a List<Object>.

You should use NumPy because it:

- Performs numerical operations much faster than normal Python lists.
- Uses less memory for large datasets.
- Supports arrays and matrices naturally.
- Provides useful functions for statistics, linear algebra, random numbers, and more.
- Is the foundation of libraries such as pandas, SciPy, scikit-learn, and many machine-learning tools.
